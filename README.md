# AI-Powered Assignment Evaluation Assistant

An AI-based system that helps evaluate student assignments using deep learning and natural language processing.

## Features

- Upload student assignment answers
- Extract text from answer sheets
- Compare answers with expected answers
- Calculate semantic similarity
- Generate AI-based evaluation results
- Faculty verification and review
- Store evaluation history

## Technologies Used

- Python
- Flask
- Deep Learning
- OCR
- NLP
- Sentence Transformers
- HTML
- CSS

## Project Structure

- `app.py` - Main Flask application
- `templates/` - HTML pages
- `static/` - CSS and static files
- `requirements.txt` - Required Python packages

## How to Run

```bash
pip install -r requirements.txt
python app.py
